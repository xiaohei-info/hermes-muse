# 功能实现对照

[返回 README](../README.zh-CN.md) · [English](FEATURE-COVERAGE.md)

这份清单按实现细节拆分，供开发和验收时查阅。日常使用能获得什么，见 README 中的功能表。

以下按当前代码、Skill 和 Cron 列出实现情况，连接器的单项操作合并列示。

- 已实现：有插件代码或原生 API 接入。
- 已配置：有 Skill/Cron 提示词流程，具体工作由模型和现有工具完成。
- 部分覆盖：已有一部分能力，缺口或接入条件写在右栏。
- 未覆盖：本插件没有对应实现。

“已配置”不表示程序能保证模型每次都正确执行；真实模型与渠道表现仍需验收。

### 内部行为尚未核实的系统任务

| Muse 任务 | 已知信息 | 本项目处理 |
| --- | --- | --- |
| heartbeat | 每 30 分钟执行一次，但原检查清单缺失 | 使用自己的主动巡查流程，不能认定为相同实现 |
| deterministic-doctor | 每小时运行，具体检查与修复逻辑未知 | 未新增对应巡检任务 |
| profile-image | 每 168 小时运行，具体动作未知 | 未新增对应任务 |

临时兴趣默认 14 天到期、无截止日期的目标在 30 天后复核研究，是本项目的规则，不是对 Muse 原始参数的复述。用户新消息可以续期兴趣，助手自己的研究和旧记忆不能续期；目标复核不会自动取消明确约定的提醒。
